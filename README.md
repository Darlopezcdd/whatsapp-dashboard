# WhatsApp Dashboard (n8n Frontend App)

A Node.js and Express-based dashboard designed to interface with n8n workflows and manage WhatsApp communications or related automated tasks.

## 🌟 Key Features

*   **Custom Frontend:** Built with EJS templating to provide a clean user interface.
*   **n8n Integration:** Communicates seamlessly with n8n backend workflows.
*   **Google APIs:** Ready to integrate with Google services using `googleapis`.
*   **File Uploads:** Supports robust file handling and uploads via `multer`.
*   **Fast API Requests:** Utilizes `axios` for external API communication.

## 🛠️ Technology Stack

*   **Backend Framework:** Node.js + Express.js
*   **Templating Engine:** EJS
*   **HTTP Client:** Axios
*   **File Handling:** Multer
*   **Integrations:** Google APIs

## 🚀 Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Environment Configuration:**
    Create a `.env` file and configure your API keys and endpoints.

3.  **Run the application:**
    ```bash
    npm start
    ```
    The server will start using `src/server.js`.
